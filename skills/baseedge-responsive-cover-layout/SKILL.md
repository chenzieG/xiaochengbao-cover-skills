# 基地边缘人物封面多尺寸重构

## 小橙报封面反馈与交付规则

单物体封面的 B 站、横版与公众号须检查文案组和主体轮廓的视觉分量，避免字大物小或缩字过度；比例反馈按共享参考中的“文案与物体的视觉比例”执行，具体迭代百分比不得固化为通用阈值。

处理已批准封面的尺寸适配、装饰遗漏、文案位置反馈、群执行诊断或交付时，必须读取 [设计保留、验收与群交付](../cover-dimensions/references/cover-workflow-lessons-20260910.md)。装饰不是固定品牌不等于可随意删除；用户指出缺失的元素必须进入本次保留清单。像素自检不能替代与原稿逐项核对。用户明确要求局部重排时按反馈执行，仍保持关联文字包装成组变换；未获得重排授权时保留本技能的成稿锁定约束。

把原稿视为设计系统，不把它当成需要缩放裁切的一张扁平图片。保持文案内容、包装语言、人物身份关系和品牌标准，针对每个画幅重新构图。

## 工作流

1. 读取原稿与全部批准案例，识别画幅、内容层级和人物类型。
2. 输出六层清单：背景纹理、环境场景、人物关系、文字、文字包装、Logo。
3. 判断构图 archetype：单人主视觉、双人并列肖像、双人互动场景、单产品主体。按对应参考规则锁定不可改变的关系。
4. 为六个尺寸分别建立构图，不复用一套绝对坐标：横版优先左右结构，竖版优先上下结构，底图遵循顶部 422px 特例。
5. 优先对背景与场景做保构图生成或扩图。文字、文字包装和 Logo 不进入生成模型。
6. 若生图改变人物身份、人数、姿势或关系，改用原像素联合保护模块；禁止矩形贴片。
7. 逐张进行真实像素与视觉审核。六张全部通过后才能交付。

## 分层边界

- 文字层：标题字形、字距、行距、颜色强调。
- 文字包装层：副标题、英文、框线、圆点、箭头、下划线、标题旁小头像。
- 人物层：真实人物及关键手势。标题旁的小头像不算场景人物。
- 环境层：厂房、火箭、桌椅、地面、星球、晶圆等空间结构。
- Logo 层：只使用批准资产，确定性合成。

禁止把文字或包装烘焙进背景后重画。禁止把人物、桌椅和环境不加区分地整张送入模型。

## 人物安全规则

- 脸、头发、颈部和关键手势零覆盖、零裁切。
- 衣服、腿部等非识别区域可在设计需要时有限覆盖。
- 双人关系模块不得拆开、换序、改变距离或在人际空间中插字。
- 双人互动场景同时锁定桌椅、视线、姿势、透视和人物距离。

## 尺寸与验收

- 竖版：1242×1660。
- 视频号：1080×1260，左右各 60px 纯白。
- Bilibili：1600×1000。
- 横版：1920×1080。
- 公众号：900×383。
- 底图：1080×1260；仅顶部 422px 为内容区，下方 838px 纯黑。

不要相信模型自报合格。直接检查成品：像素尺寸、人物头脸和手势、标题碰撞、人物比例、背景连续性、黑白边、矩形贴片、Logo 像素和坐标。
