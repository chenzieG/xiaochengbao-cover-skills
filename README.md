# 小橙报封面 Skills

小橙报／基地边缘多尺寸封面技能包，整理自 2026-09-10 的本机已安装版本。包含技能入口、配套参考、审核脚本及技能自带的两张 Logo。

## 技能选择

| Skill | 用途 |
| --- | --- |
| [cover-dimensions](skills/cover-dimensions/SKILL.md) | 六尺寸规范、图层拆分、编辑器状态、导出与验收、飞书群触发规则 |
| [baseedge-cover-production](skills/baseedge-cover-production/SKILL.md) | 新封面制作、成稿整体锁定扩图、保护像素恢复与审核 |
| [baseedge-human-cover-layout](skills/baseedge-human-cover-layout/SKILL.md) | 单人、双人、群像构图，标题避脸、完整头部与人物层级 |
| [baseedge-responsive-cover-layout](skills/baseedge-responsive-cover-layout/SKILL.md) | 获准重排时按画幅分层重构，人物关系、单产品与包装保留 |

四个技能共享 [设计保留、验收与群交付](skills/cover-dimensions/references/cover-workflow-lessons-20260910.md)，请保持四个目录并列，以保留跨技能相对链接。

## 最新更新

- **设计完整性**：浅色日历、菜单栏、选框、箭头、英文和文件夹等有意设计的元素默认保留。“不是品牌资产”不等于“允许删除”。
- **局部反馈**：用户明确要求某版下移文案或修改比例时，调整指定版本；文字与附属包装成组变换。
- **物体比例**：B 站、横版、公众号分别比较完整文案组与主体可辨认轮廓的视觉分量，避免字大物小，也避免过度缩字。案例的 15% 回调等参数不是通用阈值。
- **验收证据**：像素零差异不能证明原稿元素没有遗漏；必须另做源设计逐项核对。
- **状态与交付**：区分已生成、待复核、验收通过、已发送；进程存在不等于持续产出，消息发送成功不等于用户批准设计。
- **运行边界**：技能更新不等于机器人或进度服务已部署；本仓库不包含运行中的机器人服务。

详见 [更新记录](CHANGELOG.md) 与 [规则差异和部署条件](docs/compatibility.md)。

## 安装与使用

将 `skills/` 下的四个完整目录复制到你的 Codex skills 目录，保持同级布局。已有同名目录时先备份并比较差异，再更新。此包不附带自动覆盖安装脚本。

在能识别这些 skills 的 Codex 会话中，可使用以下请求：

> 使用 cover-dimensions 和 baseedge-human-cover-layout，修复这组封面的裁头和标题压脸问题；保持原稿人物关系，文字及包装成组调整。

> 使用 baseedge-cover-production 的成稿锁定模式，保留批准稿所有相对位置和包装，只做整体等比变换与外部背景扩图；底图按独立规则处理。

> 使用 cover-dimensions 和 baseedge-responsive-cover-layout，按六种标准尺寸重新构图。这次明确允许重排，保留主体身份、标题内容及设计装饰。

输入新封面任务时提供准确标题、主体素材和视觉参考。实际图像工作还需要可用的图像生成／编辑能力。本包自身不是一键运行的封面生成应用。

## 脚本与验证范围

- `audit_exports.ps1`：随生产技能提供的导出检查脚本，需按脚本要求在支持其依赖的环境运行。
- `restore_protected_pixels.py`：保护像素恢复与审核脚本，需要 Python 和 Pillow。
- `MANIFEST.json`：本次文件快照的 SHA-256、大小和来源记录。

本次发布检查范围为文件完整性、相对 Markdown 链接、脚本语法和隐私占位处理；不表示生成了一套新封面，也不表示脚本已在完整生产环境跑通。
