# 单产品主体封面

以宁德时代电池六尺寸手工成品为批准案例。先拆分背景、产品、文字、文字包装、Logo，再按画幅重构；禁止整图缩放。

## 不可改变

- 产品结构、透视、比例和层级不变；仅允许等比缩放和平移。不得生成、补造或改变产品零件。
- 标题文字、行序、色散效果及批准包装关系不变。
- “报废？”周围的框线、角点和控制点属于批准的科技感文字包装，不得误判为编辑器残留。
- “一次性用品”后的灰色强调条属于包装层；必须与文字绑定移动，保持原有覆盖关系，禁止矩形贴片边缘。
- Logo 不参与生图。完成画面后，按尺寸选择黑/白整画布 Logo 模板，以原尺寸、原坐标叠加到最上层。

## 六尺寸构图

- 横版、Bilibili、公众号：左侧文案、右侧产品。保留清晰分区，不让第三行和主体争抢中心。
- 竖版、视频号：上方文案、下方产品。保持完整产品轮廓与中部呼吸空间。
- 底图：只在顶部 422px 重排内容；可改为两行以适应该区域，下方 838px 必须纯黑。
- 视频号：左右各 60px 纯白，内容只放在中间 960px。

## 视觉修正

- 清除产品右侧、底部的额外黑边、灰边与抠图光晕；保留原有蓝光，但让阴影自然落入背景。
- 横版如第三行侵入产品区，优先将产品右移 2%–3%，其次将第三行缩小约 3%。
- Bilibili 产品偏弱时可放大 5%–8%，但不得碰 Logo 或侵入文字。
- 公众号产品偏小时可放大约 5%并略向左移动。
- 竖版第三行与产品之间至少保留 30–45px 视觉间距。
- 白字背景过亮时，只压暗文字背后区域约 8%–12%，不得整体压黑产品。

## 审核

1. 检查产品结构、透视和轮廓是否与原稿一致。
2. 检查包装元素是否被完整保留且未误删。
3. 检查文字与产品是否分区明确、无碰撞。
4. 检查产品边缘、阴影、蓝光和背景颗粒是否连续。
5. 检查视频号白边、底图黑区及对应 Logo 整画布模板。
6. 最多审核三遍；第三遍仍有问题时发送六张候选图并列出未通过项，不得静默停止。

## 用户确认：物体主体不得偏小（2026-09-09）

- 所有产品、设备、车辆等物体封面，都必须让主体成为清楚的主视觉。禁止为了容纳长标题，把物体缩成右下角小摆件；也禁止以“大块空背景、巨大标题、小主体”的构图交付。
- 此次华为手机与话筒的三张放大修正版是主体视觉重量参考。手机与话筒应作为联合模块等比缩放和平移，不改产品结构和内部关系。
- 横版、Bilibili、公众号优先采用左右分区；主体联合模块通常占有效画幅约40%–50%宽、70%–85%高，作为起始构图目标，不能机械套用。细长、宽扁等不同形态以实际轮廓、主体辨识度和视觉重量判断，不靠透明包围框凑占比。
- 主体偏小时先放大并调整位置，同时收紧、移动或合理重排文字区；不得继续缩小主体来躲文字。不得压住产品核心识别部位、手机镜头或Logo，不得拉伸、压扁、裁掉主体关键轮廓。
- 输出时记录主体非透明像素边界、相对有效画幅的宽高比例，并在整张缩略预览中检查。若缩略图中主体仍像角落配件，必须重新构图；像素尺寸正确不代表构图合格。
- 人物或物体混合场景仍遵守完整轮廓、原像素保护、文字和Logo规范；本条调整的是主体视觉重量，不授权重画产品或任意改变品牌资产。
